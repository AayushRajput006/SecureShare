# Blockchain workspace — Milestone 3

Run `npx hardhat --init` **inside this directory** when you have Node.js 22.13+ installed. Choose the default TypeScript Hardhat 3 setup. This creates `hardhat.config.ts`, `contracts/`, `test/`, and `ignition/` using the correct matching dependencies. The `contracts/` folder is intentionally empty at Milestone 3: the file-registry contract is Milestone 4.

Do not use any wallet with real funds or import real private keys into development tools.
