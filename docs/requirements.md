# Requirements baseline (Milestone 1)

Core: wallet identity, browser-side encryption, IPFS encrypted storage, on-chain ownership and grants, recipient-specific wrapped keys, decrypt/download, future-access revocation, integrity checks, audit events.

Constraints: zero-paid-services local demo, no plaintext keys on chain or server, never claim revocation erases previously downloaded copies, max initial file size 10 MB (provisional).
