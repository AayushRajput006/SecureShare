# Actors and use cases
Owner: connect wallet; upload encrypted file; register CID; list owned files; share with recipient; revoke future access; view transactions.
Recipient: connect wallet; view shared files; retrieve encrypted file and wrapped key; decrypt if authorized.
System: validate signatures and authorization; add ciphertext to Kubo; publish on-chain events; verify integrity.

Milestone 3 only establishes file locations, components, and placeholders.
